`urls_merged.json` (the app → URL corpus this project scans) is not
checked into git — at ~514MB it's well over GitHub's per-file limit, and
it's the raw extracted-URL dataset rather than something derivable from
anything else in this repo.

Download it from this repo's GitHub Releases and place it in this
directory as `urls_merged.json`. See the [blocklist-analysis
README](../README.md#input-data) for details.
